Real time · Embedded · Single-task

  • Real time (RTOS) · الزمن الحقيقي: يعالج البيانات فورًا بلا تأخير ملحوظ.
    مثال: RTLinux، Windows CE — وسادة هوائية أو منظم ضربات قلب.
    متى؟ عندما يكون التأخير خطرًا على السلامة أو الآلة.
  • Embedded · مدمج: برنامج داخل العتاد للتحكم بجهاز محدد.
    مثال: سيارة، تلفاز، pacemaker، مرآة ذكية، غسالة.
    متى؟ جهاز بوظيفة ثابتة لا يحتاج نظام سطح مكتب كامل.
  • Single-task / single-user · مهمة واحدة · مستخدم واحد: يشغّل تطبيقًا واحدًا فقط لمستخدم واحد.
    مثال: هاتف أساسي للمكالمات والرسائل.
    متى؟ جهاز بسيط ورخيص ووظيفة واحدة واضحة فقط.

Multitasking · Multi-user

  • Multitasking / single-user · متعدد المهام · مستخدم واحد: تطبيقات متعددة معًا لنفس الشخص.
    مثال: هاتف ذكي أو PC — متصفح + مستند + موسيقى.
    متى؟ عمل أو دراسة يومية تحتاج أكثر من برنامج في آن واحد.
  • Multi-user · متعدد المستخدمين: عدة أشخاص يستخدمون نفس المورد معًا.
    مثال: Unix، servers، Google Sheets / OneDrive، خادم مدرسة.
    متى؟ تعاون فريق أو مدرسة أو مستشفى على خادم أو سحابة مشتركة.
Choice of OS · Scenarios

متى نختار أي نوع؟

Real time / Embedded

جهاز يتحكم بآلة، أو يجب أن يستجيب فورًا بلا تأخير ملحوظ.

  • وسائد هوائية في سيارة · منظم ضربات القلب
  • فرن ذكي / غسالة / مرآة حمّام مضادة للضباب
  • لوحة قيادة رقمية أو روبوت مصنع

Single-task

جهاز بسيط رخيص ووظيفة واحدة واضحة — لا حاجة لتطبيقات متزامنة.

  • هاتف أساسي للمكالمات والرسائل فقط
  • آلة حاسبة مكتبية أو ساعة رقمية بسيطة
  • جهاز نقطة بيع قديم يعرض قائمة واحدة فقط

Multitasking · single-user

أفراد وشركات على حواسيب شخصية وهواتف: أكثر من عمل في آن.

  • طالب: متصفح + مستند + موسيقى معًا
  • موظف: Excel + بريد + اجتماع Teams
  • هاتف ذكي: خرائط + واتساب + كاميرا

Multi-user

تعاون عبر خادم أو سحابة، أو موارد مشتركة لكثير من الموظفين.

  • مدرسة: طلاب يدخلون نفس الخادم معًا
  • شركة: Google Sheets / OneDrive لفريق كامل
  • مستشفى: عدة أطباء يصلون لقاعدة بيانات المرضى
Role of the operating system

دور نظام التشغيل في الإدارة

01

Networking

الوصول لموارد الشبكة: remote printing، إدارة المستخدمين، file backup.

02

Security

فحوصات مستمرة للهجمات؛ جمع بيانات عن صحة النظام لمكافحة cyber attacks.

03

Memory management

توزيع الذاكرة بكفاءة. الأنظمة multi-user تعمل غالبًا من servers.

04

Multitasking

حصص صغيرة من زمن المعالج بالتناوب — يبدو متزامنًا.

05

Device drivers

تربط الجهاز الرقمي بالطرفيات: printers، keyboards، screens.

!

Limit

الذاكرة وقوة المعالجة محدودة — كثرة التطبيقات تبطئ الأداء.

Multitasking

يبدو متزامنًا… والمعالج يتناوب

نظام التشغيل يعطي كل process حصة صغيرة من processor time. السرعة تخدع العين فتبدو المهام متزامنة.

مثال الصف

Antivirus في الخلفية + متصفح + مستند + موسيقى = multitasking بالتناوب، لا بمعالجات لا نهائية.

Graphical (GUI)

نوافذ وأيقونات وقوائم ومؤشر. سهلة بلا برمجة. تحتاج ذاكرة وطاقة أكبر. توسّع إمكانية الوصول accessibility.

Command line

أوامر نصية. مرونة أعلى وأجهزة بمواصفات أقل. تحتاج معرفة commands. مثال: إعداد router عبر terminal.

Menu-based

وظائف عبر قائمة. ذاكرة أقل من GUI. قد تقدّم خيارات إضافية لكن تحتاج معرفة أين الوظيفة.

Adapted

تكييف اللون وحجم الخط والموضع — مهم لضعف البصر واحتياجات خاصة.

طالما عندنا واجهة رسومية (GUI) على الكمبيوتر…
ليش لسا في Command line (CLI)؟

ناقش مع زميلك دقيقة واحدة قبل ما نكشف الجواب.

GUI ↔ CMD

نفس الشغل… بطريقتين

كثير أشياء سهلة بالواجهة الرسومية لها مثيل في CMD — بس CLI مش بديل يومي دائمًا؛ هو أداة سرعة وطوارئ وفهم.

GUI → نفس الفكرة في CMD

  • مستكشف الملفات ← dir · cd
  • إعدادات الشبكة / IP ← ipconfig
  • هل الإنترنت شغال؟ ← ping 8.8.8.8
  • معلومات الجهاز ← systeminfo
  • اسم الجهاز / المستخدم ← hostname · whoami

ليش نتعلّم CLI؟

  • السرعة: أمر واحد ينفّذ عمل يحتاج عدة نقرات في GUI.
  • حالات الطوارئ: الواجهة الرسومية تعطّلت؟ الشاشة زرقاء؟ الشبكة مقطوعة؟ الـ terminal غالبًا آخر باب للوصول والإصلاح.
  • فهم النظام: تشوف شو بصير فعليًا تحت الأيقونات — مفيد للدعم الفني والبرمجة والشبكات.

الخلاصة للطالب: GUI للسهولة اليومية · CLI للتحكم السريع، الإنقاذ، وفهم كيف يشتغل الجهاز من الداخل.

Activity · Command line

جرّب CMD على جهازك

افتح cmd (Win + R ← اكتب cmd ← Enter). أوامر آمنة للقراءة فقط — لا تغيّر الشبكة ولا تحذف شيئًا.

1) من أنا على الشبكة؟

  • ipconfig — اعرف IP جهازك
  • ipconfig /all — تفاصيل أكثر (MAC, DNS)
  • getmac — عنوان MAC فقط
  • hostname — اسم الجهاز
  • whoami — اسم المستخدم الحالي

2) «Hacks» لطيفة وآمنة

  • ping 8.8.8.8 — هل الإنترنت يصل؟
  • ping localhost — اختبر جهازك نفسه
  • nslookup google.com — حوّل الاسم إلى IP
  • tracert google.com — مسار الرحلة (قد يبطئ قليلًا)
  • systeminfo — ملخص عتاد ونظام التشغيل

3) استكشاف الملفات

  • dir — محتويات المجلد الحالي
  • cd Desktop — انتقل لسطح المكتب
  • tree /F — شجرة المجلدات (جرّبها بمجلد صغير)
  • cls — نظّف الشاشة

4) لمسات ممتعة

  • color a — نص أخضر كلاسيكي
  • color 0b — خلفية سوداء ونص سماوي
  • ver — إصدار Windows
  • help — قائمة الأوامر · help ping لشرح أمر
  • echo Hello class! — اطبع رسالة

قاعدة الصف: نستخدم أوامر قراءة واستعلام فقط. ممنوع: حذف ملفات، تغيير إعدادات الشبكة، أو أوامر تؤثر على أجهزة الآخرين.

Factors affecting OS use and performance

ما يؤثر في أداء نظام التشغيل؟

Amount of data being processed

بث فيديو + تحرير أثقل من جداول ومستندات إدارية بسيطة.

Hardware specifications

الذاكرة وسرعة المعالجة. برامج خلفية كثيرة تبطئ laptop.

Compatibility with other systems

بعض البرامج لا تعمل على كل OS — مثل اختلاف Apple و Android.

Number of applications

كلّما زاد multitasking زاد الضغط على memory و CPU.

Open source × Proprietary

مبادئ وآثار المصدر

Open source

تعاوني، peer review، مجاني، قابل للنسخ والتكييف. خطر تعديل خبيث أو غير خبير — تحقق من المصدر.

Proprietary

ملك الشركة، سري، يُشترى للاستخدام لا لتعديل source code. تصحيحات من المطوّر. قد يكون مكلفًا.

When to choose

Open source أم Proprietary؟

Open source عندما

  • ميزانية محدودة مع قدرات متقدمة
  • حاجة لتكييف الشفرة أو التعلم والمساهمة
  • مصدر موثوق وتحديثات منتظمة

Proprietary عندما

  • دعم رسمي وتصحيحات مضمونة
  • توافق معروف مع بيئة المؤسسة
  • استخدام جاهز بلا تعديل المصدر

Implications for IT systems, organisations & stakeholders

آثار اختيار نوع الملف

JPEG

ضغط مع فقدان. مساحة أقل. مناسب للبريد. قد لا يكفي لجودة عالية.

PNG / GIF

ضغط بلا فقدان. PNG أشيع. GIF للصور المتحركة.

RAW

غير مضغوط؛ يحتاج برامج مناسبة للتعديل. حجم أكبر.

DOC × RTF

RTF أخف للمشاركة عبر إصدارات مختلفة. DOC للتنسيق الغني.

MP3 × MPEG / AVI

MP3 صوت. ملفات الفيديو أكبر. توافق وأمان الملفات يؤثران على الاستخدام.

Stakeholders

تحديث الأنظمة قد يؤخر العمل. عدم التوافق يعيق العملاء والموردين والموظفين. الانتقال يحتاج تدريبًا.
